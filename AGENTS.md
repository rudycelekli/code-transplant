# Code Transplant

Use TypeScript and the compiler's symbol graph. Keep extraction, adaptation, and behavioral evidence separate. Never report universal equivalence from a finite corpus. Each implementation change includes an ADR and relevant verification. Preserve donor notices and content hashes. Unknown dependencies or effects must produce a refusal or an explicit boundary entry. Do not execute unfamiliar code merely to inspect it. Verification executes user-selected trusted code in subprocesses, which are not security sandboxes.
